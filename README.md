Little project spun up after ChatGPT wanted me to pay 20 dollars a month. The predicament I found myself in was I've been playing CTF's. Mostly terrible at them, need a hint or two, but looking directly at the walkthrough sort of kills the fun. 

Anyways, Groq provides pretty cheap inference (the chepaest I think?) and I found this search that advertised the same: GoogleSerper. In any case just plug in your API keys, and spin it up. The front-end using pnpm and the python backend is using uv. 

Hope you find it educational! 


ENV vars needed:

GROQ_API_KEY 
SERPER_API_KEY
